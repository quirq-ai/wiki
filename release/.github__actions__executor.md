### install.sh

Install qqrelease with the python on PATH: PyPI packages by hash only (requirements.txt),
then the qq packages by commit (requirements-qq.txt) and this repo, built without fetching
anything else. pip check fails if something they need is missing. Run from the repository
root with PYTHONSAFEPATH=1. presubmit runs this too, so a stale hash or a missing package
fails there. Fails fast (`set -e`).
