### hub-sync.mjs

Runs the spacehub agent "liftoff" on this computer: node scripts/hub-sync.mjs (or hub-
sync.cmd on Windows) Liftoff's queue file lives in a spacehub project
(hub/quirq/launch/queue.json). This keeps that project, and the rest of the space around it,
in step with the hub both ways, pushing as the agent.
