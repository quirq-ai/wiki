### present.js

Default presentation for a research topic. Run from a topic folder: present build render
README.md, GOAL.md and output/{onepager,slide,report} into a static site in dist/, and add
each built app present dev build, then serve dist/ on $PORT (default 3000) Markdown files
become .html pages; any other file under those output folders (a PDF, an image, an HTML
deck) is copied as-is.
